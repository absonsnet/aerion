## Description of Service

Daak is an open-source desktop email client by ABSONS Technologies. The official Daak project page is https://github.com/absonsnet/daak

Daak allows you to connect to email accounts via IMAP/SMTP, send and receive emails, manage email folders and organisation, sync contacts from CardDAV, Google, and Microsoft services, and use OAuth authentication for Gmail and Outlook.

Daak is a local application that runs on your computer. We do not provide any cloud services, email hosting, or server infrastructure.
